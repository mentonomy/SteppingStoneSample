# F# Example: Stepping Stone Algorithm
I wrote this sample F# code a few years ago, mainly as an exercise for myself, but also in the hope it may have some use for others who get into functional programming for the first time, as was the case for myself.
It was then buried and almost got lost with some other projects in the late Codeplex, but I've salvaged the code and created this Git repo from it. It'll need some updating to properly run again, and I hope I'll get to this over time.

For some explanations on what's in here, please peruse what I wrote at the time here somewhere: [Blog](https://blog.rautenberg.dev/search/label/F%23).
